# Ledger: staged-scene test

- Voices: Chatterbox (MIT) on Runpod RTX A5000, cfg 0.4, seed 7, slowed with atempo 0.9. Reference clips made with Kokoro (bf_emma narrator, bf_isabella Mrs Penrose, bf_alice Mara, bm_george Tom).
- Sound effects: synthesised in `mix_staged.py` (no recordings).
- Rain: synthesised. Fire: "Fire Crackling" by AntumDeluge, OpenGameArt, CC0 (https://opengameart.org/content/fire-crackling), stretched into an endless bed by `winter-fireplace/fire_bed.py`.
- A = narration with character voices, no effects. B = staged dialogue + soft effects.
- Pod cost: about $0.03.
