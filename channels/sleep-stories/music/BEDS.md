# Background sound beds (like rain and fireplace)

Rule: every story gets a bed that matches where it happens. Steady, no sudden loud sounds. Rain first (most popular); thunder only very distant and only in non-sleep sections.

| Bed | Fits stories set in | Source |
|---|---|---|
| Rain on window / roof | inns, cottages, attics | made in code (done) |
| Fireplace | cabins, lodges, inns | CC0 recording, stretched (done) |
| Ocean waves on a shore | lighthouse, beach cottage, harbour | code or CC0 recording |
| Wind outside / soft blizzard | mountain lodge, winter cabin | made in code (done) |
| Stream / brook | forest cottage, mill, garden | CC0 recording needed |
| Night crickets / summer night | farmhouse porch, meadow | CC0 recording needed |
| Forest at night (owls far off, leaves) | woodland cabin | CC0 recording needed |
| Night train (rhythm on rails, rain on glass) | sleeper-train journey stories | code for rhythm + CC0 for carriage |
| Old ship creaking + gentle sea | voyage / boat stories | CC0 recording needed |
| Ticking clock | bookshop, grandparent's house | made in code |
| Cat purring | any cosy indoor scene | made in code (done) |
| Café / library murmur, very soft | bookshop, tea-room stories | CC0 recording needed |
| Brown noise (deep, soft hum) | under any bed, for masking | made in code |

Layering: one main bed + an optional soft brown-noise floor; a scene change (outside -> inside) crossfades over about 3 s.
Every recording used must be CC0 or owned, logged in the video's ledger.
